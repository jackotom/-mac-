# v0.3.11 Critical Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复正式包外部页面加载、非法实时状态锁死和日志处理失败丢数据，同时保持现有开发启动、记牌、竞技场和悬浮窗功能不变。

**Tech Stack:** Electron、React、TypeScript、Vitest、Vite。

```ts
const trustedHosts = new Set(["localhost", "127.0.0.1", "[::1]"]);

export function resolveTrustedDevServerUrl(
  devServerUrl: string | undefined,
  isPackaged: boolean,
  query: Readonly<Record<string, string>> = {}
): string | undefined {
  if (isPackaged || !devServerUrl) return undefined;
  const url = new URL(devServerUrl);
  if (url.protocol !== "http:" || !trustedHosts.has(url.hostname) || url.username || url.password) {
    throw new Error("VITE_DEV_SERVER_URL 必须是无账号信息的本机开发地址。");
  }
  for (const [key, value] of Object.entries(query)) url.searchParams.set(key, value);
  return url.toString();
}
```

在 `main.ts` 增加唯一入口 `loadRendererPage(window, query)`；全部八处 `loadURL/loadFile` 分支改用该入口。正式包忽略环境变量并调用 `loadFile`，开发环境只调用验证后的 `loadURL`。

```ts
function isCardTrackerRow(value: unknown): boolean {
  return isRecord(value) && isNonEmptyString(value.name) && isPositiveInteger(value.count) &&
    [value.remaining, value.drawn, value.played].every(isNonNegativeInteger) &&
    isOptionalString(value.cardId) && (value.details === undefined || isCardDetails(value.details)) &&
    (value.unresolved === undefined || value.unresolved === true);
}

function isTrackerEvent(value: unknown): boolean {
  return isRecord(value) && isNonEmptyString(value.id) && isNonEmptyString(value.at) &&
    isOneOf(value.kind, ["game-start", "game-end", "draw", "friendly-play", "opponent-play", "arena-pick", "zone-change", "info"]) &&
    isOneOf(value.player, ["friendly", "opponent", "unknown"]) &&
    isOptionalPositiveInteger(value.turn) && isOptionalString(value.cardName) &&
    isOptionalString(value.raw) && isOptionalString(value.cardId);
}
```

```ts
const previousPending = wasTruncated ? undefined : this.pendingLogBytes.get(logPath);
const { text, pending } = splitCompleteLogChunk(previousPending, buffer);
// Process text first. Do not mutate offsets, pending bytes, or fingerprint here.
```
