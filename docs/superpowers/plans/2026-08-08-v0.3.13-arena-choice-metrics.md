# v0.3.13 竞技场选牌四项指标 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 竞技场三选一和地下竞技场重选时，在三张游戏卡牌下方分别显示真实的“抽到影响 / 对套牌影响 / 选取率 / 6+胜选取率”。

**Architecture:** Firestone 职业单卡统计模块负责把 `drawnThenWin / drawn` 与职业总体胜率比较，形成 `drawnImpact`；现有 `deckImpact`、`pickRate`、`highWinPickRate` 继续复用。新增独立的悬浮条指标模块，避免改变主窗口已有的评分三格。运行时校验、缓存恢复和发布验收贯穿同一状态接口。

**Tech Stack:** Electron、React、TypeScript、Vitest、CSS、Firestone 公共 JSON。

## Global Constraints

- 版本从 `0.3.12` 升到 `0.3.13`。
- 指标必须来自真实 Firestone 数据，不得用评分、打出胜率或猜测值冒充。
- `抽到影响 = drawnThenWin / drawn × 100 - 职业总体胜率`。
- `对套牌影响 = decksWithCardThenWin / decksWithCard × 100 - 职业总体胜率`。
- 影响值固定两位小数，不加正号、不带百分号；选取率固定一位小数并带 `%`。
- 高胜标签按真实桶显示：6 胜桶显示“6+胜选取率”；只有其他桶时显示真实门槛，不伪造 6 胜数据。
- 悬浮条保持鼠标穿透、窗口高度 `62px`、三张候选左右顺序不变；缺值显示“暂无”。
- 主窗口的现有“评分 / 选取率或胜率 / 高胜数据”三格保持不变。
- 旧职业缓存必须兼容，并在缺少抽到统计时触发刷新；断网时仍可读取包含原始计数的新缓存重算影响。

- 字体：沿用系统中文字体；标签 9–10px，数字 11–12px，数字使用等宽排版特性。
- 布局：每张候选牌下方一个 `236px × 52px` 的 2×2 网格。

```text
┌──────────────┬──────────────┐
│ 抽到影响 -1.85 │ 对套牌影响 -1.75 │
├──────────────┼──────────────┤
│ 选取率 16.8%  │ 6+胜选取率 10.2% │
└──────────────┴──────────────┘
```

- 识别特征：同类指标成行对比；影响数字按正负着色，底板保持透明深色，不卡住炉石点击。

- [ ] **Step 3: 扩展共享接口并计算真实影响**

```ts
export interface FirestoneCardRating {
  readonly drawnWinrate?: number;
  readonly drawnWins?: number;
  readonly drawnSampleSize?: number;
  readonly drawnImpact?: number;
}

export interface ArenaCardRating {
  readonly drawnImpact?: number;
}
```

职业解析使用：

```ts
const drawnSampleSize = numberValue(entry.stats.drawn);
const drawnWins = numberValue(entry.stats.drawnThenWin);
const drawnRatio = ratioValue(drawnWins, drawnSampleSize);

...(drawnRatio === undefined ? {} : {
  drawnWinrate: roundPercent(drawnRatio * 100),
  drawnWins,
  drawnSampleSize,
  drawnImpact: roundPercent((drawnRatio - overallRatio) * 100)
})
```

缓存保存原始 `drawnWins/drawnSampleSize`，读取后重算派生值。职业缓存加 schema 版本；缺少当前 schema 时作为 stale 后台刷新，网络失败仍返回旧缓存已有数据。

- [ ] **Step 3: 新建悬浮条专用深模块**

```tsx
export function ArenaChoiceOverlayMetrics({ choice }: { readonly choice: ArenaCardChoice }) {
  const highWinLabel = choice.rating?.highWinThreshold
    ? `${choice.rating.highWinThreshold}+胜选取率`
    : "高胜选取率";
  return (
    <section className="arena-choice-metrics arena-choice-overlay-metrics" role="group" aria-label={`${choice.name} 的竞技场指标`}>
      <ImpactMetric label="抽到影响" value={choice.rating?.drawnImpact} />
      <ImpactMetric label="对套牌影响" value={choice.rating?.deckImpact} />
      <RateMetric label="选取率" value={choice.rating?.pickRate} />
      <RateMetric label={highWinLabel} value={choice.rating?.highWinPickRate} />
    </section>
  );
}
```

`formatImpact` 使用 `toFixed(2)`，`formatRate` 使用 `toFixed(1) + "%"`；影响值通过 `is-positive/is-negative/is-neutral` 着色。`ArenaChoiceOverlayPanel` 统一使用该模块，删除无评分特例。主窗口继续使用原 `ArenaChoiceMetrics`。
