# 国服天梯推荐数据接入设计

## 目标

让左侧天梯推荐窗自动识别本机炉石版本，并且只展示同版本、明确来自国服、达到最低统计场次的标准或狂野卡组。任何关键条件无法确认时停止推荐，并准确说明原因。

## 范围

本阶段包含：

- 从本机炉石安装读取完整版本，并归一化为用于匹配的主补丁版本。
- 将版本识别、国服数据获取、数据校验和界面状态拆开。
- 接入一个由项目控制的统一 JSON 数据入口。
- 校验数据的地区、版本、时效、模式、胜率、场次和卡组代码。
- 按版本和模式缓存最近一次通过校验的数据。
- 在左侧窗口显示真实版本、来源、更新时间和准确的失败原因。

本阶段不包含用户对局匿名上传。只有在确认网易盒子不存在可持续使用且许可明确的数据入口后，才单独设计匿名统计系统。

## 方案选择

采用“本机版本识别 + 受控数据转换入口”。桌面端不直接解析网易网页，也不信任第三方页面自称的国服标签。

原因：网页结构可能随时变化；把上游适配放在受控入口后，上游变化只需修复一处，已安装的桌面应用无需同时更新。桌面端只消费固定格式并执行最终校验。

## 本机版本识别

新增独立版本识别模块，返回完整版本、主补丁版本、地区和证据来源。

识别顺序：

1. 读取炉石应用的 `Info.plist`。
2. 使用 Battle.net 的本机产品记录交叉确认安装路径、版本和国服标记。
3. 默认路径不存在时，从 Battle.net 安装记录寻找真实路径。

版本统一规则：`36.0.246003` 和 `36.0.0.246003` 都归一化为主补丁 `36.0`。卡牌网站版本不能代替本机游戏版本。

炉石升级导致主补丁变化时，旧补丁推荐立即失效并重新获取。识别失败时不使用上次版本悄悄兜底。

## 统一数据入口

服务端定时读取经过确认的国服来源，将数据转成固定 JSON。优先核对网易游戏盒子实际使用的数据入口、使用条件、稳定性和字段完整性；只有满足要求才接入。

顶层数据必须包含：格式版本、地区、游戏补丁、生成时间、来源名称、来源地址、抓取时间和卡组列表。

每条卡组必须包含：唯一编号、标准或狂野、统计分段、卡组名、职业、胜率、场次、卡组代码、牌表和更新时间。胜率、场次与卡组代码必须来自同一条统计记录。

桌面端只访问 HTTPS 白名单入口，不直接抓取资讯文章、微博正文或人工推荐页面。

## 校验规则

只有同时满足下列条件的数据才能展示：

- 地区明确为国服。
- 数据补丁与本机主补丁完全一致。
- 数据时间不在未来，且未超过允许时限。
- 模式与当前标准或狂野模式一致。
- 胜率、场次和最低样本门槛合法。
- 卡组代码能够真实解码，牌数、职业和模式合理。
- 来源在允许列表内，且数据格式版本受支持。

单条坏记录被隔离并记录原因；整批顶层信息不可信时整批拒绝。不能因为某条记录写了 `CN` 就认定为真实国服数据。

## 缓存与更新

缓存按“主补丁 + 模式”分开，保存数据格式版本、来源、获取时间、校验结果和网络更新标记。

- 正常每六小时检查更新。
- 在线更新失败时，只能使用同主补丁且仍在有效期内的最近成功缓存。
- 使用缓存时明确显示“缓存”和实际更新时间。
- 缓存超过允许时限或版本不一致时停止展示。
- 写入使用临时文件替换，避免中途退出破坏缓存。

## 左侧窗口状态

正常状态显示当前模式、完整炉石版本、国服来源、更新时间、胜率、场次、牌表和复制按钮。

失败状态明确区分：

- 没找到炉石安装。
- 无法读取炉石版本。
- 当前安装不是可确认的国服。
- 国服数据源尚未接入。
- 网络更新失败且没有可用缓存。
- 数据格式或校验异常。
- 当前版本暂无达到最低场次的卡组。
- 缓存已过期。

错误区使用短标题和一句说明；只有用户能解决的版本识别问题才显示“重新检测”。数据源缺失时显示“等待国服数据”，不诱导用户重启。

## 验证标准

自动测试覆盖：

- 默认路径和 Battle.net 自定义路径的版本识别。
- 两种版本格式归一化。
- 炉石升级后旧缓存失效。
- 国服、版本、时间、模式、胜率、场次和卡组代码校验。
- 网络失败时同版本有效缓存可用，跨版本或过期缓存不可用。
- 所有失败状态的界面文案和操作。
- 正常状态展示版本、来源和更新时间。

实际验收覆盖：

- 在当前 `36.0.246003` 国服安装上识别为主补丁 `36.0`。
- 断网后状态符合缓存规则。
- 用不匹配版本样本验证推荐被拒绝。
- 打开安装包，实际查看左侧窗口的加载、正常、缓存和失败状态。
- 完整运行类型检查、自动测试、构建、签名校验和安装包启动检查。

## 安全与隐私

版本识别只读取本机安装信息。桌面端不读取游戏内存、不注入进程，也不上传账号、聊天、牌库收藏或个人信息。本阶段不上传用户对局数据。
