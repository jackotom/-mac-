# 运行状态小窗设计

## 目标

主窗口收起或普通启动隐藏主窗口后，保留一个可见、可识别的运行状态小窗，让用户能确认记牌器仍在运行，并可一键恢复主窗口。

## 行为

- 普通启动继续不弹出完整主窗口，改为显示运行状态小窗。
- 主窗口最小化或关闭到后台时显示运行状态小窗。
- 状态小窗显示应用名和当前状态：监听中、已暂停、缺少日志或读取失败。
- 点击状态小窗主体恢复并聚焦主窗口，随后隐藏状态小窗。
- 状态小窗提供明确的关闭按钮；关闭只隐藏状态小窗，不退出记牌器。
- 点击 Dock 图标或再次打开应用仍恢复主窗口。
- 现有对局记牌小窗、对手小窗和竞技场数据条保持原有逻辑，不被状态小窗替代。

## 界面

- 使用独立小型桌面窗口，尺寸约 260 x 88。
- 深色 Mac 工具风格，显示绿色、黄色或红色状态点和一行短状态文字。
- 窗口可拖动，保存上次位置；显示器变化后自动移回可见区域。
- 不始终置顶，不遮挡炉石；作为真实窗口保留，便于用户从桌面和 Dock 确认程序仍在运行。

## 数据与边界

- 状态来自现有记牌服务，不增加新的日志读取或网络请求。
- 主进程负责窗口创建、显示、隐藏、位置恢复和 IPC。
- 渲染层只负责展示状态和触发恢复主窗口。
- 状态数据异常时显示明确错误，不使用伪造的“运行中”兜底。

## 验收

- 冷启动后不弹完整主界面，但能看到状态小窗。
- 主界面最小化或关闭到后台后，状态小窗出现。
- 小窗能正确展示监听、暂停和异常状态。
- 点击小窗能恢复主界面。
- 点击 Dock 图标能恢复主界面。
- 现有记牌小窗仍只按炉石前台状态显示和隐藏。
- 自动测试、类型检查和构建全部通过。
- 打包版实际启动后验证收起、恢复、拖动和退出流程。
