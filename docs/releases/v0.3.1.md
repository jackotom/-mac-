# v0.3.1

## 修复

- 对手牌库、手牌等区域已经知道真实总数时，直接显示剩余张数，不再错误显示 `≥0`。
- 只有总数未知、但已经确认部分卡牌时才显示 `≥N`；完全未知显示 `?`。
- 星空投影球详情优先显示本局实际施放法术数量和名单，保留重复法术。
- 存在本局法术记录时，隐藏空的“生成/关联法术（0）”，避免把静态卡牌资料误认为本局统计。
- 对手奥秘候选现在保留完整卡牌资料；鼠标悬停或键盘聚焦候选即可查看费用和实际效果。
- 修正对局历史异步测试的竞态，发布验收不再偶发失败。

## 原因

- 区域显示错误使用了“已识别牌名数量”，忽略引擎已经提供的真实总数。
- 截图中的投影球问题来自仍在运行的旧版进程；0.3.0 的本局法术数据未被旧进程加载。
- 奥秘候选资料原本已经由卡牌库生成，但前端转换时遗漏了详情字段。
