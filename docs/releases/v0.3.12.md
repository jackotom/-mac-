# v0.3.12

## 修复

- 分行实体快照先合并同一实体的标签，不再因 `ZONE` 与 `CONTROLLER` 到达顺序不同而漏掉本方初始牌库。
- 本方身份未知时暂存带控制器的区域变化，等待完整玩家证据后按原顺序处理，不再把未知一方当成对手。
- 活跃竞技场收到精确牌组后原位同步基础牌组和同卡记录，不重置当前对局、回合、手牌、实体或对手数据。
- 推断式自动匹配至少需要两张不同的本方已观察卡；炉石显式选中的套牌仍立即生效。

## 验证要求

- 两种分行标签顺序都必须得到相同的本方牌库快照。
- 身份确认前不得产生伪造的对手出牌；确认后必须按原顺序恢复双方记录。
- 活跃竞技场精确牌组同步后，对局状态和已有记录必须保持，基础牌组按最新证据对账。
- 单张观察卡不得触发推断式匹配；第二张不同卡满足置信条件后才能匹配，显式选中不受该门槛影响。
