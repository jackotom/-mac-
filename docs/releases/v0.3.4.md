# v0.3.4

## 修复

- 修复真实卡牌编号带 `CORE_`、`VAN_` 前缀时，奥秘永远无法被排除的问题。
- 修复同一奥秘的核心、经典和原始版本重复显示并出现相互矛盾状态的问题。
- 修复部分官方卡牌资料缺少奥秘标签，导致法术反制、爆炸符文等真牌漏出候选池的问题。
- 修复内层效果结束时过早判断奥秘未触发的问题。
- 修复一个奥秘触发后，其他奥秘被同一动作错误排除的问题。
- 修复“异议”和“绑架”的测试身份写反，导致异议规则未被真实验证的问题。

## 增加

- 支持根据完整的施放法术、使用随从和攻击对方英雄动作排除确定不可能的奥秘。
- 支持满场限制和“无法被反制”例外；条件不完整时保持“可能”，不冒险误排除。
- 排除状态显示具体原因：法术未触发、随从未触发、攻击英雄未触发。
- 奥秘候选继续支持图片、悬停卡面和效果说明。

## 验证

- 使用本机真实炉石卡牌缓存验证：法师候选由 37 条重复记录合并为 23 张真实奥秘。
- 使用嵌套动作、奥秘触发、多槽位、攻击目标和满场场景做回放测试。
