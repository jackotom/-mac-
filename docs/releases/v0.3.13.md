# v0.3.13 竞技场选牌指标

竞技场三选一和地下竞技场重选现在在每张候选牌下方显示四项统计：抽到影响、对套牌影响、选取率和高胜选取率。

- 抽到影响：`drawnThenWin / drawn × 100 - 职业总体胜率`。
- 对套牌影响：`decksWithCardThenWin / decksWithCard × 100 - 职业总体胜率`。
- 选取率和高胜选取率使用 Firestone 公开统计；影响值保留两位小数，选取率保留一位百分比。
- 高胜标签按真实数据桶动态显示。6 胜桶显示“6+胜选取率”；若只有其它桶，则显示实际门槛。
- 旧职业评分缓存缺少抽到统计时会触发后台刷新。新缓存保存原始计数，离线时仍能重新计算影响值。
- 任一统计没有真实数据时显示“暂无”，不会用评分、出牌胜率或其它胜场桶填充。

本版本发布验证会保留并检查 `arena-choice-overlay.png` 和对应 inspection JSON，确认四个标签都在打包应用的选牌窗口中出现。

本版本尚未进行 Apple 公证。
