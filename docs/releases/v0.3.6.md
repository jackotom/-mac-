# v0.3.6

## 修复

- 修复传说团队卡牌正文被误当成第四张候选，导致三张牌的选取率和胜率全部不显示的问题。
- 修复三字中文传说牌名识别错一个字后无法自动纠正的问题。
- 修复同名随从和英雄皮肤并存时，可能选错卡牌版本并丢失统计的问题。
- 修复带数字、英文和中文混排的机械牌名识别失败问题。

## 改进

- 竞技场画面按左、中、右三张卡的位置分别识别，不再把正文关键词混进候选牌。
- 三张牌暂时只认出两张时，先在正确位置显示两张数据，缺失位置显示“识别中”，后续自动补齐。
- 识别范围只保留竞技场可选卡牌，排除英雄皮肤和内部占位牌。

## 验证

- 使用用户提供的恶魔猎手传说团队截图重放，正确识别“希希集”“伊莉达·寻罪”“克罗妮卡”并读取实际选取率和胜率。
- 使用完整本机卡牌库扫描 1,004 张可选传说牌，全部可按正式名称识别。
- 验证正文“流放”不会成为第四张候选，三字牌名一字误差可纠正，同名英雄皮肤不会抢占随从统计。
- 验证两张到三张的自动补齐、槽位不偏移，以及完整结果不会被后续残缺画面覆盖。
