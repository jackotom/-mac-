# v0.3.0

## 新增

- 显示真实回合、当前行动方和法力状态。
- 出牌、已使用和疑似烧毁记录显示发生回合。
- 牌库按法力值从低到高排序，同费按名称排序，未知费用置后。
- 记录卡牌效果向牌库创建的剩余数量，例如“天空主母创建 / 5张卡牌”；双倍触发按实际数量统计，抽取后实时递减。
- 记录已知的置顶、置底卡牌；牌库洗牌后立即清除位置记录，来源剩余数量不受影响。

## 修复

- 修复星空投影球详情无法读取本局已施放法术数量和已识别法术的问题，双方数据彼此隔离。
- 修复匣中古神实际施放结果缺失，支持双倍释放、重复法术和嵌套古神。
- 修复手牌已满时烧毁的牌仍留在手牌区的问题。
- 修复对手小窗出现大块空白、全局效果挤占记牌区的问题。
- 修复竞技场选牌被评分排序、实战阶段仍显示选牌面板的问题。

## 显示规则

- 来源统计只显示来源名称和剩余张数，不展开生成牌明细。
- 已知生成牌仍按普通牌显示在牌库列表；身份未公开时才显示未知。
- 洗牌只取消置顶、置底关系，不删除牌库中的牌，也不改变已知牌名。
