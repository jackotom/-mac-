# v0.3.11

## 修复

- 正式安装包始终加载内置页面，忽略外部 `VITE_DEV_SERVER_URL`；开发版只接受不含账号信息的本机 HTTP 地址，全部窗口统一执行该限制。
- 补全牌库、事件、统计和卡牌详情等记牌状态校验；非法实时状态不再抢占合法初始化或覆盖最后一次有效状态，后续合法更新可以自动恢复。
- 日志游标改为在本批完整日志处理成功后提交；临时处理失败时保留原游标并自动重试，界面推送失败不会重放已处理日志，避免内容丢失或重复生效。

## 验证要求

- 正式包注入外部开发地址后仍只能加载内置页面，开发模式的本机地址和全部窗口入口保持可用。
- 坏牌库、坏事件和负数统计必须被拒绝；非法实时更新后，合法初始状态和后续合法实时状态都能正常显示。
- 模拟日志处理临时失败时，不追加新字节也能从原位置重试；截断、快速替换和并发读取行为保持正常。
- 完整测试、类型检查、正式构建、差异检查和安装包实机启动验收全部通过后方可发布。

- 正式构建、类型检查、差异检查和生产依赖扫描通过，生产依赖漏洞为 0。
